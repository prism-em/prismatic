# Prismatic

Full documentation, installers, tutorials, etc may be found at [www.prism-em.com](http://www.prism-em.com)

**Notice as of January 2026**: Prismatic is no longer actively maintained. We appreciate any future interest or use, but will be less able to troubleshoot issues or push updates to the software in the future. For a list of other (S)TEM simulation software, please see [https://prism-em.com/resources-sim-codes/](https://prism-em.com/resources-sim-codes/). For a recently updated and actively maintained TEM simulation package, we especially recommend [abTEM](https://abtem.github.io/doc/intro.html) (link to [their Github](https://github.com/abTEM/abTEM)).
